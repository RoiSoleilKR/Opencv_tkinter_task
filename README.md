# 영상처리 실습 프로그램 (tkinter + OpenCV)

- **학번**: 202610069
- **이름**: 김홍용
- **GitHub**: https://github.com/RoiSoleilKR/Opencv_tkinter_task

tkinter로 만든 GUI 기반 영상처리 프로그램입니다.
이미지를 불러온 뒤 메뉴에서 기능을 선택하면, 슬라이더와 라디오버튼으로 파라미터를 조절하면서 결과를 **실시간**으로 확인할 수 있습니다.

- 왼쪽: 원본 이미지 / 오른쪽: 처리 결과 이미지
- 하단: 선택한 기능에 맞게 바뀌는 조절 패널

## 실행 방법

### 1. 필요한 라이브러리 설치
```bash
pip install opencv-python numpy pillow
```
(tkinter는 Python에 기본 포함되어 있습니다.)

### 2. 실행
```bash
python Opencv_tkinter_task.py
```

## 사용 방법
1. 상단 메뉴 **파일 → 열기**로 이미지(png, jpg, jpeg, bmp)를 불러옵니다.
2. **화소처리 / 영역처리 / 기하학처리** 메뉴에서 원하는 기능을 선택합니다.
3. 하단 조절 패널의 슬라이더, 라디오버튼으로 결과를 조절합니다. (초기화 버튼이 있는 기능도 있습니다.)
4. **파일 → 저장**으로 결과 이미지를 저장합니다. (화면에는 틀에 맞게 축소되어 보이지만, 저장은 처리된 원래 크기로 됩니다.)

## 구현한 기능

### 파일
| 기능 | 설명 |
|---|---|
| 열기 | 이미지 불러오기 (한글 경로 지원) |
| 저장 | 결과 이미지를 png / jpg로 저장 (한글 경로 지원) |

### 화소처리
| 기능 | 설명 |
|---|---|
| 밝기 및 대비 조절 | 밝기(beta), 대비(alpha) 슬라이더로 조절 |
| 히스토그램 평활화 | 그레이스케일 변환 후 `cv2.equalizeHist` 적용 |
| 그레이스케일 / 색 반전 / 이진화 | 라디오버튼으로 선택, 이진화는 기준값 슬라이더 조절 |

### 영역처리
| 기능 | 설명 |
|---|---|
| 블러링 | `blur`, `GaussianBlur`, `boxFilter`, `medianBlur` 중 선택 + 커널 크기 조절 |
| 샤프닝 | 기본 / 고강도 / 라플라시안 / 언샤프 마스킹 중 선택 |
| 엣지 검출 | Canny(임계값 2개), Sobel, Laplacian(커널 크기) 중 선택 |

### 기하학처리
| 기능 | 설명 |
|---|---|
| 확대/축소 & 보간법 | 배율 조절, 최근접 / 양선형 / 양3차 / 영역 보간법 비교 (결과 크기 표시) |
| 회전 & 평행이동 | 회전 방식 3가지 선택 (`cv2.rotate` 고정 각도 / 회전 행렬 직접 계산 후 `cv2.warpAffine` / `getRotationMatrix2D`) + 가로·세로 이동 |
| 전단 | 가로·세로 전단 (이미지가 잘리지 않도록 결과 크기 자동 계산) |
| 어파인 변환 | 이미지의 세 점을 이동해 `cv2.getAffineTransform`으로 변환 |
| 원근 투시 변환 | 이미지의 네 점을 이동해 `cv2.getPerspectiveTransform`으로 변환 |

## 코드 구조
- 모든 기능은 `open_○○_menu()` 함수 하나로 구성되며, 같은 틀을 따릅니다.
  1. 조절 패널 초기화 (`clear_control_frame`)
  2. 실제 처리를 수행하는 `apply_○○()` 함수 정의 → 결과를 `im2`에 저장하고 화면에 표시
  3. 라디오버튼 / 슬라이더 생성 (`make_slider` 도우미 함수 사용)
  4. 최초 1회 `apply_○○()` 실행
- `im1`은 원본, `im2`는 처리 결과이며, 저장 시 `im2`가 저장됩니다.
- `show_image()`는 이미지를 표시 틀(360x300)에 맞게 축소해서 보여줍니다. 처리 자체는 원본 크기로 수행됩니다.
- 확대/축소는 `show_image_zoom()`으로, 확대된 경우 가운데 부분만 잘라서 보여줍니다.
